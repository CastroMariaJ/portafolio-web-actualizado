## 🌟 Características Principales

- 🎨 **Estilo Minimalista & Tecnológico**: Diseño limpio en paleta de colores neutros (blanco, gris, negro y beige sutil) enfocado en la experiencia de usuario (UX/UI).
- 📱 **Totalmente Responsivo**: Layout responsivo adaptado para computadores, laptops, tablets y smartphones utilizando CSS Grid, Flexbox y media queries.
- ⚡ **Desarrollado en Pure Vanilla**: 100% HTML5 semántico, CSS3 y JavaScript Vanilla sin dependencias de frameworks externos.
- 🚀 **Sección de Proyectos**:
  - **TalentAI (Proyecto Destacado)**: Tarjeta interactiva con resumen profesional del sistema de preselección de candidatos utilizando automatizaciones en **n8n**, inteligencia artificial (**OpenRouter**), almacenamiento en **Google Sheets**, bot de **Telegram** y métricas visuales con **Chart.js**.
- 🛠️ **Sección de Conocimientos**: Tarjetas con tecnologías clave (*Python, HTML, CSS, JavaScript, Bases de Datos, MySQL*) y nivel de **Inglés (A2 — Nivel Básico)**.
- 📩 **Contacto Directo**: Integración directa de correo electrónico (`castromariawork@gmail.com`), cuenta de **GitHub** (`CastroMariaJ`) y formulario interactivo.

## 🚀 Cómo Ejecutar Localmente

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/CastroMariaJ/portafolio-web-CastroMariaJ-actualizado.git
   ```
2. **Navegar al directorio**:
   ```bash
   cd portafolio-web-CastroMariaJ-actualizado
   ```
3. **Abrir en el navegador**:
   Haz doble clic sobre el archivo `index.html` o abre el proyecto con la extensión **Live Server** en VS Code.
