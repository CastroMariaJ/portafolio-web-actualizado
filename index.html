Proyecto Destacado

TalentAI — Sistema Inteligente de Selección y Preselección de Candidatos

TalentAI es una plataforma web desarrollada para optimizar y automatizar el proceso de selección y preselección de candidatos. El sistema recibe hojas de vida en formato PDF, procesa el flujo automatizado mediante n8n e integra modelos de inteligencia artificial a través de OpenRouter para evaluar perfiles en función de los requisitos de una vacante. Genera diagnósticos de compatibilidad, almacena información en Google Sheets y permite realizar consultas interactivas vía Telegram, ofreciendo métricas claras complementadas con Chart.js.

HTML5 CSS3 JavaScript n8n OpenRouter Google Sheets Telegram Chart.js
